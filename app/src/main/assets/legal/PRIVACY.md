# 隐私与数据使用

本说明适用于 ChatHelp Android 1.4.1-glm。无需登录本项目，没有开发者运营的数据中转服务器或自建分析服务。

## 截图、OCR 与聊天文字

开启无障碍后，助手读取受支持聊天应用当前页面的文字；读不到时，可用系统截图和本机 ML Kit 中文 OCR。截图用于内存识别，本分支不会把聊天截图发送给智谱。关闭设置中的本机 OCR 后，仅使用可读取的无障碍文字；部分聊天界面将无法识别。

本机 OCR 的输入图片与识别结果由设备处理。但是 ML Kit SDK 会向 Google 发送性能、使用量等统计信息，并可能请求设备兼容性信息；不能将“离线可识别”理解为 SDK 完全没有网络通信。详见官方条款：https://developers.google.com/ml-kit/terms 。中文识别模型随 APK 打包，不需要首次联网下载。当前仅验证过启用了 Google Play 服务的设备断网识别，未完成无 GMS 设备测试。

分析时会将读取到的聊天文字、关系设定和所选上下文发送给设置中指定的模型平台。默认直接连接 https://open.bigmodel.cn/api/paas/v4 。模型平台按其服务条款处理数据，请仅处理你有权使用的内容，避免提交不必要的敏感信息。完整流程测试使用内置虚构对话，但仍会向所选模型发起真实请求。

云端图片理解默认关闭、不参与聊天采集；高级设置中主动开启并测试时，测试图片会发送到该视觉接口。

## 密钥与本机记录

API Key 保存在应用私有 SharedPreferences 中，当前未做额外加密；禁止系统备份，不写入源码和应用日志。取得设备高权限的人仍可能读取。判断与回复仅在相同接口域名下继承密钥；切换预设清除不适用的凭据。

联系人、知识库位于应用私有目录；聊天历史默认关闭，主动开启后保存至本机 files/kb。仅用户选中的相关上下文参与模型请求。可在知识库界面删除条目；系统“清除数据”或卸载会删除本应用本机设置与记录。

“复制”或“填入”操作可能将回复写入系统剪贴板，其他具有相应权限的软件可能读取。程序不自动点击发送，不读取聊天应用数据库。

## 权限与退出

无障碍用于读取和填入；悬浮窗用于显示建议；前台服务/通知用于提示运行。可关闭助手、关闭 OCR、撤销权限或卸载。免费模型价格与服务可用性由平台决定；更换为其他模型时需自行核对费用及隐私政策。
